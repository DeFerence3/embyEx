Design system

Marquee, extended for Home: artwork leads, the system font keeps EmbyEx part of the OS, and the mint/amber palette with asymmetric shapes gives it its own identity. Three rules: one primary action per screen, nothing that only works with a gesture, and status always in words and icons, never colour alone.

Color primitives

Semantic roles

New for Home: on-scrim roles for text and controls on artwork, and three artwork stand-in hues (real artwork is images).

Contrast (WCAG 2.2 AA)

System font only (system-ui / Roboto / Segoe UI / Cantarell). Identity comes from colour, shape and motion.

Buttons

Resume is the only filled button on Home. Labels are verbs. Targets ≥ 48 px.

Source chip

Tells people where Home's content comes from. Status = icon + words, never colour alone. 32 px visual, 48 px hit area. Opens the status sheet.

Cards and the shared lift

One animation for every card, so no card needs its own shape change: hover and keyboard focus scale the art 1.04 with elevation 2 and zoom the artwork 1.06 inside its frame; pressed 0.97; focus adds a 3 px ring. Spring: motionScheme fast spatial. Reduced motion: shadow and ring only.

Spotlight and filmstrip

The top of Home. The filmstrip is a tab list controlling the spotlight; it never moves by itself. Position (“1 of 8”) is announced politely. Desktop adds Previous / Next.

Bottom bar

Today's pill, fixed: icon on every tab, label always visible, current = indicator + filled icon + bold label. Account button labelled “Account and settings, Maya”.

Error and feedback framework

Every message lands on one surface. Decision order: 1. needs a decision or can't be undone → T6; 2. tied to one input → T1/T2; 3. Home can't show its content → T5; 4. a lasting condition → T4; 5. otherwise → T3.
