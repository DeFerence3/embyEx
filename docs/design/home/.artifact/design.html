Design system

Marquee, extended for Home: artwork leads, the system font keeps EmbyEx part of the OS, and the mint/amber palette with asymmetric shapes gives it its own identity. Three rules: one primary action per screen, nothing that only works with a gesture, and status always in words and icons, never colour alone.

Color primitives

Semantic roles

New for Home: on-scrim roles for text and controls on artwork, and three artwork stand-in hues (real artwork is images).

Contrast (WCAG 2.2 AA)

Typography

System font only (system-ui / Roboto / Segoe UI / Cantarell). Identity comes from colour, shape and motion.

Spacing

Shape

Cards md (20), spotlight controls full, sheets xl. Emblems keep the asymmetric EmbyEx corner (36/24/36/12).

Elevation

Icons

Buttons

Resume is the only filled button on Home. Labels are verbs. Targets ≥ 48 px.

Source chip

Tells people where Home's content comes from. Status = icon + words, never colour alone. 32 px visual, 48 px hit area. Opens the status sheet.

Cards and the shared lift

One animation for every card, so no card needs its own shape change: hover and keyboard focus scale the art 1.04 with elevation 2 and zoom the artwork 1.06 inside its frame; pressed 0.97; focus adds a 3 px ring. Spring: motionScheme fast spatial. Reduced motion: shadow and ring only.

Spotlight and filmstrip

The top of Home. The filmstrip is a tab list controlling the spotlight; it never moves by itself. Position (“1 of 8”) is announced politely. Desktop adds Previous / Next.

Bottom bar

Today's pill, fixed: icon on every tab, label always visible, current = indicator + filled icon + bold label. Account button labelled “Account and settings, Maya”.

Card menu and sheet

Edit Home controls

Loading, empty and error pieces

Error and feedback framework

Every message lands on one surface. Decision order: 1. needs a decision or can't be undone → T6; 2. tied to one input → T1/T2; 3. Home can't show its content → T5; 4. a lasting condition → T4; 5. otherwise → T3.

Shell and global states

Navigation, the source chip and its status, the player handoff, and keyboard operation. The bottom bar keeps today's pill; the fixes are icons and labels on every tab, a labelled account button and 48 px+ targets.

Keyboard and focus

Focus is always visible (3 px ring in focus-ring, plus the card lift) and never hidden behind the sticky top bar or bottom bar: scrolling keeps 72 px clear above and 96 px below the focused element.

Focus order on Home

  1. Source chip
  2. Refresh
  3. Spotlight title (opens Details)
  4. Resume
  5. ⋮ More options
  6. Filmstrip (one tab stop, ← → inside)
  7. Previous / Next (desktop)
  8. See all 8
  9. New in Movies: See all, then the shelf (one tab stop, ← → inside), then ⋮ of the focused card
  10. … each following shelf the same way
  11. Edit Home
  12. Bottom bar: Home, Libraries, Search, Account

Keys

Tab / Shift+TabMove between groups: chip, Refresh, spotlight title, Resume, ⋮, filmstrip, See all, each shelf, Edit Home, bottom bar
← →Inside the filmstrip or a shelf: previous / next title (the filmstrip changes the spotlight)
Home / EndFirst / last title in a filmstrip or shelf
EnterOpen the focused title (on the filmstrip: play it)
Shift+F10 or Menu keyOpen the card menu for the focused title
Ctrl+RRefresh Home
EscClose a menu, sheet or dialog; focus returns to the control that opened it

Reduced motion: the spotlight switches without sliding, the lift keeps only the shadow and ring, and the reconnecting icon stops spinning.

Home

The first screen after sign-in. Primary question: “What do I watch now?” The spotlight answers it with one Resume button; the filmstrip shows everything else in progress; shelves below show what's new.
