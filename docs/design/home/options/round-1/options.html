Round 1 · three layouts for Home

Palette, shapes and the system font are fixed by the Marquee direction, so these differ in layout and card treatment. All three share: a Resume hero (one primary action), the source chip in the top bar, a count + See all on every section, a ⋮ on every card, Edit Home at the end, and the fixed bottom bar (icon + label on every tab).
