Keyboard and focus

Focus is always visible (3 px ring in focus-ring, plus the card lift) and never hidden behind the sticky top bar or bottom bar: scrolling keeps 72 px clear above and 96 px below the focused element.

Focus order on Home

  1. Source chip
  2. Refresh
  3. Spotlight title (opens Details)
  4. Resume
  5. ⋮ More options
  6. Filmstrip (one tab stop, ← → inside)
  7. Previous / Next (desktop)
  8. See all 8
  9. New in Movies: See all, then the shelf (one tab stop, ← → inside), then ⋮ of the focused card
  10. … each following shelf the same way
  11. Edit Home
  12. Bottom bar: Home, Libraries, Search, Account

Keys

Tab / Shift+TabMove between groups: chip, Refresh, spotlight title, Resume, ⋮, filmstrip, See all, each shelf, Edit Home, bottom bar
← →Inside the filmstrip or a shelf: previous / next title (the filmstrip changes the spotlight)
Home / EndFirst / last title in a filmstrip or shelf
EnterOpen the focused title (on the filmstrip: play it)
Shift+F10 or Menu keyOpen the card menu for the focused title
Ctrl+RRefresh Home
EscClose a menu, sheet or dialog; focus returns to the control that opened it

Reduced motion: the spotlight switches without sliding, the lift keeps only the shadow and ring, and the reconnecting icon stops spinning.
