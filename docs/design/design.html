Design system

Marquee: the artwork sets the mood, the interface stays quiet. Three rules guide every screen: one filled button (Play), every other action tonal with a visible label, and text only ever on solid surface, never on raw artwork.

Color primitives

EmbyEx's existing ink-and-mint palette with a warm amber accent. Screens use only the semantic roles. On Android, wallpaper colors can replace these through dynamic color; the role structure stays the same.

Semantic roles

art-1…3 only paint the artwork stand-ins in this file; they're identical in both themes because a backdrop image doesn't change with the theme.

Contrast (WCAG 2.2 AA)

Typography

The platform's system font (Roboto on Android, Segoe UI on Windows, the desktop font on Linux), so EmbyEx feels part of the OS. No bundled third-party fonts. Display for the title when there's no logo image; title for section headings; tabular figures for times, sizes and percentages.

Spacing

Shape

12 for chips, menus and snackbars, 20 for tiles and photos, 28 for dialogs, 36 for sheets, full for Play.

Elevation

Icons

Material Symbols Rounded, filled variant for active toggles and Play.

Play button

The only filled button on the details screen. Label says exactly what happens: Play, Resume from 1:12:40, Play again, Play episode.

56 dp tall, full width on compact. Starting keeps its width. Disabled only while the item is still loading; offline it plays the downloaded copy.

Buttons

Tonal and text buttons for everything that isn't Play. Danger only inside a confirmation.

Targets ≥ 48 dp. The back button sits on a solid surface circle so it stays visible on any artwork.

Action tile

Secondary actions with icon and visible label. Toggles use aria-pressed; the label changes with the state where it helps (Mark watched → Watched).

64 dp tall, 8 dp gaps. State shows by fill, filled icon and label, never color alone.

Download tile

The download status lives in the third tile. It opens the version picker, then a menu with Pause/Cancel or Play from server/Remove.

Progress = ring + percentage text. Screen readers hear the same information as the visual label.

Track chip

Shows the current audio or subtitle choice and opens the picker. One audio track → static label.

48 dp tall. aria-haspopup=menu, aria-expanded while open.

Menu and radio items

Anchored menu on medium and expanded windows; the same items in a bottom sheet on compact.

Rows 48 dp. Radio state = ring + dot. Tags (SDH, Forced, Commentary) explain variants in text.

Version row

Choosing what to download. Size is always visible because it's the cost.

Rows 64 dp, role=radio inside a radiogroup.

Cast & crew tile

3:4 rounded-rectangle photo (portrait headshots crop badly in circles), name and role underneath. Crew roles get a small label.

Whole tile is one link. Names clamp to 2 lines; the full name is in the accessible label and on the person page.

Episode card

Season rail cards. Watched, in-progress and current each have a text marker.

Current card is outlined 3 dp and labelled Now viewing.

Shell & behaviour

How the details screen sits in the app and behaves across input methods, window sizes and system settings.

Window sizes

Layout follows the window width, never the platform name. A desktop window dragged narrow gets the phone layout; a tablet in landscape gets the desktop layout.

  • Compact < 700: artwork on top fading into the page, single column, full-width Play, three equal action tiles.
  • Medium 700–1099: taller artwork, head column max 640, Play sized to content, Media info as a side column.
  • Expanded ≥ 1100: artwork bleeds right, head column on a left scrim, body in two columns. Text never sits on less than a fully opaque scrim.

Keyboard, remote and screen reader

  • Opening details puts focus on Play (desktop, TV remote) so Enter starts watching; screen readers start at the title heading.
  • Tab / Shift+Tab follow the numbered order below. Arrow keys move inside the action row, chip row and rails. Esc closes a menu/sheet, otherwise goes back.
  • Rails scroll the focused card into view with scroll-margin so focus is never hidden at an edge (WCAG 2.4.11).
  • Toggles announce state ("Favorite, toggle, on"); the download tile announces progress ("Downloading, 42%") and updates politely, at most every 10%.

Motion

  • Expressive spring on Play press (shape squish) and on toggles (fill morph). Hero artwork fades in over 300 ms; no parallax.
  • With reduced motion: springs become 150 ms fades, the artwork appears without fade, progress rings update without animation.
